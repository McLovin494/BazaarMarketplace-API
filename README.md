# Express + TypeScript Starter

A minimal backend starter using **Express.js and TypeScript**. No database, ORM, authentication, or extra framework included.

## Requirements

- Node.js 20 or newer
- npm

## Setup

```bash
npm install
```

## Run in development

```bash
npm run dev
```

Server: http://localhost:5000

Try:
- `GET http://localhost:5000/api`
- `GET http://localhost:5000/api/health`

## Build and run

```bash
npm run build
npm start
```

Compiled JavaScript is generated in `dist/`.
